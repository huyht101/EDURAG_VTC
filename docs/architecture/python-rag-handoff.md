# Python/Data-RAG handoff

Đây là canonical action register cho Python upstream. `python-service/` chỉ là tracked integration snapshot; mọi patch dưới đây phải được upstream vào repository Python. Node contract ở [internal RAG contract](../api/internal-rag-contract.md). Offline/mock/contract PASS không phải live Python–Qdrant–provider E2E PASS.

## Boundary và release notes

- Python không gửi hoặc sở hữu document `pageCount`; Node đếm original PDF hoặc generated DOCX PDF preview.
- Python không ghi MySQL; Node không truy cập Qdrant.
- Patch snapshot cần upstream chính xác: `models/schemas.py`, `services/callback.py`, `services/ingestion.py`, `services/rag_engine.py` và các test tương ứng.
- Existing vectors dùng identity/payload cũ cần quyết định re-ingest riêng; không tự gọi đó là migration hoàn tất.
- Live E2E vẫn **OPEN/BLOCKED** cho tới khi có isolated Python/Qdrant/provider runtime được phép. Bounding box/PDF highlight vẫn **OPTIONAL/LATER**.
